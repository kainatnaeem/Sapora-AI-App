# Sapora-AI-App
Sapora is an AI-powered image analysis app that understands images, scans receipts, extracts useful information, and provides intelligent insights. Built with React, FastAPI, Firebase, and OpenAI.

# 🌿 Sapora — AI-Powered VLM Application

**Sapora** is a Vision-Language Model (VLM) based AI application designed to understand and analyze visual content. It allows users to upload images, ask questions about them, and receive intelligent, context-aware responses.

Sapora also includes a dedicated **AI Receipt Scanner** that can understand receipt images, extract merchant details, dates, purchased items, quantities, prices, taxes, and totals, and turn them into meaningful spending insights.

## ✨ Features

* 🖼️ **AI Image Analysis** — Upload images and ask questions about their content.
* 🤖 **Vision-Language Understanding** — Uses AI to interpret visual information and provide contextual answers.
* 🧾 **Smart Receipt Scanning** — Extracts structured information directly from receipt images.
* 🛍️ **Purchase Detection** — Identifies purchased items, quantities, categories, and prices.
* 💰 **Spending Analysis** — Calculates totals, average prices, taxes, and spending categories.
* 📊 **Visual Spending Insights** — Highlights spending patterns and the largest purchases.
* 💡 **AI-Powered Insights** — Generates useful observations based on the analyzed receipt.
* 🔐 **User Authentication** — Secure user authentication with Firebase.
* ☁️ **Receipt History** — Saves scanned receipts and allows users to access their previous analyses.

## 🛠️ Built With

**React • FastAPI • Python • Firebase • OpenAI Vision**
